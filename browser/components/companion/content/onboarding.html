What's new on flowstate

July 11, 2022

Installation made easy
The Flowstate installation experience has been improved to help you easily transition from install to browsing.
New illustrations
Set aside a session to check out new Companion illustrations made in collaboration with Humble Beings, a project by Sunjin Kim, a Korean American artist and creative director based in Washington.
A new home screen
We beautified Flowstate’s home screen with a crisper gradient, perfect for when you’re starting a session fresh.
Never miss an event again
We’ve updated event cards to always appear above your media, so they’re always front and center.
Cursor updates
The cursor has been updated to be more visible when hovering over a calendar event.
